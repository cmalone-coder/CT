Direct volume rendering (GPU raymarching) of the raw CT density field for bone/metal/soft tissue — no surface mesh is extracted for that layer, so there's no decimation, no marching-cubes faceting, and no mesh debris to introduce artifacts. Bone (including teeth, rendered as one continuous dense structure) comes from density alone; metal hardware is highlighted using the validated segmentation label. An optional "Segmented parts" layer adds decimated meshes from an independent deep-learning segmentation (DentalSegmentator, run separately in 3D Slicer) for individually selectable maxilla/mandible/teeth/nerve-canal.
For informational discussion only — not a diagnostic tool.
